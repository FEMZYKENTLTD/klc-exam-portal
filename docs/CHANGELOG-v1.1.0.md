# KLC CBT Suite v1.1.0 — Release Notes

**Date:** 2026-10-02 · **Base:** v1.0.0 (tag `v1.0.0`, commit `6b277fd`)

v1.1.0 is the "modernisation + proof" release: every dependency moved to the
current 2026 release line, the last stub features were completed, and — for
the first time — **every interface is verified pixel-level with real
screenshots rendered by the shipped code** (closing the last documented
verification gap from the v1.0 directive build).

## 2. Features completed (no more stubs)

* **Results screen exports are real** (`ResultsViewController`):
  * *Export Report Card* → generates the official report-card PDF via
    `ReportCardService` for the selected student and term.
  * *Export Transcript* → full JSS1–SS3 transcript PDF.
  * *Graduation Certificate* → issues the certificate PDF, gated to SS3
    students only (precise refusal otherwise).
  * *Notify Result* → emails the student's registered email address through
    the configured SMTP service.
* Screenshot/verification harness (`tools/screenshot-harness/`): boots the
  real application headless (Monocle software pipeline), seeds a demo school
  (staff, 7 students, parent, question bank, live exams, attempts, results,
  CA scores, announcements, social graph) and captures every interface.

## 3. Interface verification — screenshots shipped

`docs/screenshots/` now contains renders of the actual application running
the v1.1.0 build (light + dark themes), generated by
`tools/screenshot-harness/KlcShotHarness.java`. The README carries the full
tour. This closes the honest boundary recorded in
`VERIFICATION-REPORT-DIRECTIVE-2026-09-06.md` ("pixel-level verification
needs a desktop run").

## 4. Compatibility

* Java 17 runtime unchanged — the zero-JDK Windows bundle is unaffected.
* H2 2.5 is a drop-in for the local cache; the AES-at-rest and
  backup/restore test suites cover the migration paths.
* OkHttp 5 is source-compatible for the public API this app uses
  (`OkHttpClient`, `Request`, `WebSocket`, `WebSocketListener`).
